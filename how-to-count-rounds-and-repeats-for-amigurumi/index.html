How to Count Rounds and Repeats When Making Amigurumi

Use one counter for rounds and a linked repeat counter for patterns like 'increase every 6th round'. In Rowby the repeat counter follows your rows and resets itself each time the repeat is done, and you can add extra counters for stitches and reminders on specific rounds.

Get Rowby on the App Store

Steps

  1. Start a project. Pick a ready-made project or start your own.
  2. Add a repeat. Add a repeat counter, for example every 6 rounds.
  3. Count rounds. Tap after each round; the repeat counter advances and resets itself.
  4. Add a stitch counter. Add a free counter for stitches in the round and set a target.
  5. Leave a reminder. Add a reminder to a round, such as 'Round 36: start the border'.

FAQ

How do I count rounds in amigurumi?

Count every round with a main counter, and use a repeat counter for the 'every Nth round' parts so you do not have to calculate.

Can I count stitches as well as rounds?

Yes. Add extra counters for stitches and set a target.

Does Rowby include patterns?

It includes ten ready-made projects (granny square blanket, ripple blanket, beanie, market bag, socks, dishcloth and more) that set up counters and reminders. Each points to video tutorials and free written patterns hosted elsewhere.

Can I put in my own amigurumi pattern?

Yes: PDF, photo or camera scan.

Is it free?

Free to start with one project and 30 counted rows. Repeat counters and unlimited projects are part of Pro for multiple use.

What does Pro cost?

US prices: $29.99 per year with a 7-day free trial, $4.99 per month, or $59.99 once.

Does it track yarn?

Pro includes a yarn stash with weights, colours and what is left after each project.
